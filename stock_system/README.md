# Stock Trading System V1

מערכת מחקר ו-Paper Trading לשוק ההון האמריקאי, נפרדת ממערכת ה-BTC.

## מטרה
לבנות מערכת אוטומטית, שמרנית יחסית, שמטרתה צמיחת הון לאורך זמן תוך הגבלת סיכון. אין יעד מובטח של תשואה או של 5,000 ש"ח למיליון; המטרה ההנדסית היא לשרוד, למדוד edge, ולתת לריבית-דריבית לעבוד אם ה-edge אמיתי.

## V1 – כללי בטיחות
- Long only
- ללא מינוף
- ללא אופציות / חוזים / שורט
- סיכון מקסימלי לעסקה: 0.5% מההון
- עד 3 פוזיציות במקביל
- עצירת מערכת במחיקת שיא של 12% (kill switch מחקרי)
- נכסים ראשונים: SPY, QQQ
- נתוני Daily ב-V1
- מצב ברוקר: PAPER / SHADOW בלבד

## Pipeline
Market Data -> Strategy -> Signal -> Risk Manager -> Backtest -> Robustness -> Paper -> Shadow -> Live קטן

## אסטרטגיות V1
1. Trend Breakout – מגמה ארוכה + פריצת שיא 20 יום.
2. Pullback Trend – קנייה של תיקון בתוך מגמה חיובית.

רק אסטרטגיות שעוברות Backtest, Walk-forward, Robustness ו-Paper יורשו בעתיד להתחבר למסחר אמיתי.

## הערה משפטית/מיסויית
הקוד מיועד למסחר עצמי בלבד. לפני מעבר לכסף אמיתי דרך ברוקר זר יש לוודא התאמה לחשבון של תושב ישראל, הרשאות API, חובות מס ודיווח, ומגבלות רגולטוריות רלוונטיות. אין כאן ייעוץ מס או משפטי.
